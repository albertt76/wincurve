Bottom-up roster model · snapshot

NBA projected records

Built from each team's current roster: every player's impact per 100 possessions is projected from his own history with age curves applied, weighted by expected minutes, then the season is simulated game by game on a real schedule.

Read the ranges, not the numbers. This model's average miss in backtesting is wins, against for sportsbook preseason lines — so it does not beat the market on aggregate accuracy, and the point estimates deserve less trust than the intervals. Bars show the 80% and 50% ranges; those are calibrated (a nominal 80% range contained the true result 79.6% of the time). Ranges widen with roster turnover, which measurably predicts larger errors.
On the what-if tool. Roster edits are computed the same way the model computes a team, but the model was validated on whole rosters, not on single-player swaps. The impact-to-rating slope is fitted to map a team's aggregate talent onto its rating, and it absorbs some compression in the underlying player metric, so one-player counterfactuals extrapolate it further than the backtest checked. Treat the direction and rough scale as meaningful and the exact number as indicative.
