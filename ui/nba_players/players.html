Read these as projected talent inputs, with the model's honest caveats. Impact is a per-100-possessions rate (offense + defense versus an average player), aged and shrunk — not a win count and not last season's box score. Defense is the model's weakest metric: box-score defense is positionally biased (it partly measures "is a center"), so treat the Def column, and low ratings for celebrated perimeter defenders, with caution. These are the same per-player numbers the team panels of the main projection gate behind premium; on aggregate the model does not beat the betting market — the value is per-player, per-team disagreement, not a ranking to bet on.
